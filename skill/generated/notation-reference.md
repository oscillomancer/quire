# Notation reference

Generated by `notation-ref` from the notation compiler's tables and compiled examples. Regenerate with `tools/gen/update-generated.sh`.

A single numbered bar can use the implicit `voice main`. Bars sum to the meter; `|` continues the next bar without another number, though `| N:` is also accepted when N is that bar. The default is 4/4 at 960 ticks per quarter note.

| Token | Ticks at PPQ 960 |
|---|---:|
| `w` | 3840 |
| `h` | 1920 |
| `q` | 960 |
| `e` | 480 |
| `s` | 240 |
| `t` | 120 |
| `x` | 60 |
| `q.` | 1440 |
| `q..` | 1680 |
| `e3` | 320 |
| `s5` | 192 |
| `s6` | 160 |
| `s7` | fractional |
| `e9` | fractional |
| `h+e` | 2400 |
| `700t` | 700 |

Dots: `q.` and `q..`. Tuplets use a suffix: `e3`, `s5`, `s6`, `s7`, `e9`. Add durations with `+` (`h+e`) or use exact ticks (`700t`). A rest is `r:DUR`; `r:*` fills the bar.

## Articulations

| Suffix | Effect |
|---|---|
| `'` | Half note length, minimum one tick |
| `>` | Add 20 velocity, maximum 127 |

A trailing `~` ties matching adjacent notes; `&` layers a note without advancing the bar cursor.

| Word | Velocity |

| `mf` | 80 |
| `mp` | 64 |
| `p` | 48 |

The default velocity is 96. `:NN` sets note-on velocity; `:NN/MM` also sets note-off velocity.

## Worked examples

### Implicit melody

Input:

```text
notation 1
1: C4:q E4:q G4:h
```

Canonical decompile:

```text
notation 1
ppq 960
meter 4/4

voice c1v1 ch 1 vel 96
1: C4:q E4:q G4:h
```

### Chord and dynamics

Input:

```text
notation 1
voice keys vel 80
1: mp {Cm7}:h {G7}:h
```

Canonical decompile:

```text
notation 1
ppq 960
meter 4/4

voice c1v1 ch 1 vel 64
1: [C3 Eb3 G3 Bb3]:h [G3 B3 D4 F4]:h
```

### Drum grid

Input:

```text
notation 1

```

```text

```
