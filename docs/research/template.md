## Creating a product

`AGENTS.md` identity checklist: choose display/code names, permanent reverse-DNS CLAP ID, version, AU manufacturer/subtype, effect/instrument category and layouts; replace `Starter`/`starter`/`STARTER`, ID suffix, AU `StFx`, source/header paths, namespace, font names and Objective-C class prefix. Replace state magic before first release, then preserve old versions. Set `HOST_SMOKE_PLUGIN_ID`, `HOST_SMOKE_PLAIN_PARAM`, and optional latency-changing parameter in root CMake. Describe DSP/latency/state first, implement in SDK-free core, append parameter IDs, adapt Theme/Widgets/editor, and clean configure after renaming. `AGENTS.md` tells proprietary products to choose their own license; those products are GPL-3.0-or-later and their source must not be copied into Quire. Ferric/Plateau/Vellum add `analysis/`, product DSP, more parameters, and distinct GUI; Loupe also separates instance state into `Instance.h`. Ferric/Plateau/Loupe use state version 1; Vellum uses version 2 (`plugin/src/vellum_clap.cpp:kStateVersion`). These are examples of divergence, not licensed implementation sources for Quire.

## Parameters and state

`StarterParams.h:ParamId` reserves IDs 0..5: Input Gain, Output Gain, Mix, Bypass, Input Level, Output Level. `kParams` gives ID, name, module, min/max/default, stepped, readonly, bypass, unit. IDs are saved-session ABI: never reorder/recycle; retire slots and append. `toNormalised/fromNormalised` linearly clamp; `formatValue` emits `Bypassed`/`Active`, integer percent for Mix, signed two-decimal/unit otherwise; `formatCompact` is editor shorthand. `parseValue` accepts bypass words or finite `strtod`, divides Mix input containing `%` by 100, clamps to bounds. It does not require consuming the entire input string, a potential host-text validation weakness. `starter_clap.cpp:paramInfo` maps readonly/automatable, stepped and bypass flags; `paramValueToText/paramTextToValue` delegate to table helpers. `Editor.cpp` and `Widgets.h` use the same table for controls and normalized editing.

`starter_clap.cpp:stateSave/stateLoad` writes little-endian 32-bit magic `STR1`, version 1, count, then non-readonly `(uint32 ID, IEEE double bits)` pairs. Load rejects wrong magic/future version/truncated fields; starts from defaults, ignores unknown/read-only IDs and clamps known values, then calls `pushParams` and requests `CLAP_PARAM_RESCAN_VALUES`. No product-specific migration exists yet. CLAP hosts receive this opaque stream through `CLAP_EXT_STATE`; clap-wrapper bridges format state. The vector allocation here is in a non-audio state callback, but large/unbounded input is not capped and non-finite serialized values are not explicitly rejected.

## Processing and GUI

`starter_clap.cpp:plugProcess` drains editor edits, applies CLAP value events at their sample offsets, and renders spans to the next event. It supports float/double and separate/in-place buffers. `apcCount/apcGet/apcSelect` advertise mono and stereo effect configurations, selectable while inactive, with reciprocal in-place port pairs and 64-bit support. `plugActivate` prepares scratch and DSP; a channel mismatch during processing errors instead of allocating. `Processor.h:prepare/setParams/reset` snaps the first restored values after prepare/reset, then smooths input/output/mix at 15 ms and bypass at 5 ms. `latencySamples` currently returns zero; `latGet` exposes it through CLAP latency. Latency-changing products need a host restart/callback policy and bypass compensation. `runChunks` gates meter work through atomic `telemetryOn`, taking observations at ~250 Hz only while an editor is shown; `Telemetry.h:Ring` drops new items on overflow.

Pugl 0.5.7 owns the native embedded X11/Win32/Cocoa view and events; NanoVG draws with GL2 on Linux/Windows and local Metal renderer on macOS. `Window.cpp` owns Pugl life cycle, scaling, DPI/backing ratio, `puglUpdate`, events and rendering. `Editor.cpp/Widgets.h` own drawing and input; `Theme.h` owns tokens/fonts and 820x480 design coordinates. `Window.cpp` makes one transform from design space to view; `Gui.h:adjustSize` preserves aspect and clamps scale to 0.6..2.0. Wrapper requests a 16 ms host CLAP timer; macOS/Windows have a native fallback. X11 fallback needs `puglUpdate`, so Linux host timer refusal can leave the editor static. Linux embedding is `CLAP_WINDOW_API_X11`, native XID passed to `guiSetParent`, then `Window.cpp:puglSetParent`. `tools/linux_host_probe.cpp` creates an X11 parent, captures pixels, and tests resize/hide/reopen/timer teardown while audio runs.

CTest checks: `core`, `editor-input`, `wrapper-automation`, `wrapper-timer`, `host-smoke`, `host-smoke-mono`; `auv2-bundle` only on macOS. `starter-cli` renders WAV through the same DSP; `starter-gui-preview` draws to PPM only; `starter-clap-probe` exercises CLAP host lifecycle; `starter-linux-host-probe` tests actual X11 embedding. These are separate from format validators and real host testing.

## Quire integration proposals for orchestrator review

1. Add `com.suppleaudio.semantic-params` lookup in `starter_clap.cpp:plugGetExtension`. Expose immutable semantic descriptors keyed by the same stable IDs as `kParams`; define extension ABI/version separately. A semantic state writer should reference the existing CLAP state IDs and version, not create a parallel source of defaults. Hosts without the extension continue using `CLAP_EXT_PARAMS` and `CLAP_EXT_STATE`.
2. Generate `StarterParams.h:kParams` plus semantic descriptor data from one checked-in schema with stable integer IDs, units, curves, tags and groups. Keep linear `toNormalised/fromNormalised` only for linear entries and supply curve-specific inverse mappings. Generate deterministic tables and test every ID, default, text round trip and retired slot. Alternatively extend `ParamDef` in place first, preserving its leading IDs and wrapper/editor consumers. Do not change state wire IDs.
3. Do not directly add multiple unmodified template copies with `add_subdirectory`: global `starter-*` targets/functions, `STARTER_*` cache options, FetchContent names, `${CMAKE_SOURCE_DIR}` font script reference, and `${CMAKE_BINARY_DIR}/starter_assets` collide. Rename each product's target/function/option prefix and use a shared dependency owner/cache with one set of pins and aliases; pass project-local source/binary dirs, or isolate unchanged products with `ExternalProject` and explicit artifacts. Decide a single version/pin policy before combining.
4. An instrument is feasible, but the starter is an effect. Change descriptor features/category, `apCount/apGet` to zero inputs and output-only configurations, remove in-place pairing, add CLAP note port extension/consumption and note event processing, implement voice state in the SDK-free core, update AU instrument type, and adapt host-smoke and offline tests to send notes. The current `plugProcess` returns early without input, so an unmodified template cannot sound as an instrument.
