# B2: REAPER capacity comparison

**Result (2026-10-01, REAPER 7.81, same machine/device/session as B1):** REAPER
with its default anticipative FX **fails at N = 1** (an audio underrun within
300 s), like Quire without anticipation; Quire with anticipation sustains
**30** ([b1.md](b1.md)). The xrun column counts changes of REAPER's
last-underrun timestamp between polls: this run saw two changes but the
timestamp ended at 0, so at least one underrun occurred and the second change
may be a reset rather than a second event.

Two harness bugs were fixed before this run: REAPER's Linux audio modes are
0 JACK / 2 Dummy / 3 PulseAudio (the private configs had used 1 and 3), and
play pressed right after `Audio_Init` was stopped by the device's own startup
(the script now lets the device settle for a second).

The RPP uses B1's exported notation MIDI and CLAP states for Orrery, Facet
and Ballast, including the monitored track and master limiter. No ReaEQ/ReaComp
substitutions are made. REAPER's anticipative FX preferences stay at default.
Offline renders prove generation/loading and are not capacity measurements.
The xrun count is observed changes to audio/media underrun timestamps; see
the guide for its polling limitations.
