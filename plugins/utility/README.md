# Utility

The stock stereo utility for Quire. See [integration notes](QUIRE.md),
[the utility guide](../../skill/guides/utility.md) and
[the authoritative spec](../../docs/specs/stock-effects.md#8-utility--plumb-utility).

Build from the monorepo with `cmake --preset dev` and
`cmake --build --preset dev -j6`. The isolated template build uses local
vendored dependencies and produces the display-named CLAP in plugins/clap.
