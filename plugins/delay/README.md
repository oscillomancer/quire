# Delay

A stock stereo delay with transport sync, fractional timing glide, alternating
stereo echoes, deterministic wow, loop filtering/saturation, ducking and freeze.
The display name lives in `cmake/Identity.cmake`; the CLAP artifact is emitted
under the monorepo build's `plugins/clap/` directory.

See [integration](QUIRE.md), [verification](VERIFICATION.md) and the
[parameter/recipe guide](../../skill/guides/delay.md). Copy-derived code remains
MIT; dependencies and font licenses are retained in THIRD_PARTY/NOTICES.
